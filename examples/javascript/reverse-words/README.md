# Invertir palabras

Escribe `reverseWords(sentence)`: regresa la frase con las palabras en orden inverso, separadas por un solo espacio y sin espacios en las orillas.

```js
reverseWords("te espero en el puente"); // "puente el en espero te"
reverseWords("  hola   Inde  "); // "Inde hola"
reverseWords(""); // ""
```
