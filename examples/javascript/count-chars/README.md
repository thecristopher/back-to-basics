# Contar letras

Escribe `countChars(text)`: regresa un objeto con cuántas veces aparece cada caracter.

- Mayúsculas y minúsculas cuentan como la misma letra (todo en minúsculas).
- Los espacios no se cuentan.

```js
countChars("Leon"); // { l: 1, e: 1, o: 1, n: 1 }
countChars("Ada ada"); // { a: 4, d: 2 }
countChars(""); // {}
```
