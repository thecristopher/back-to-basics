# Palíndromo

Escribe `isPalindrome(text)`: regresa `true` si el texto se lee igual al derecho y al revés.

Solo cuentan letras y números: ignora mayúsculas, espacios y signos. Los tests no usan acentos.

```js
isPalindrome("Anita lava la tina"); // true
isPalindrome("A man, a plan, a canal: Panama"); // true
isPalindrome("Claire"); // false
isPalindrome(""); // true
```
